# 🔍 Basic Port Scanner in Python

This is a simple command-line Python script that scans open ports on a specified IP address within a user-defined port range. It's a beginner-friendly project for learning about socket programming and basic network scanning.

---

## 🚀 Features

- ✅ Scans a given IP address for open ports  
- ✅ Accepts custom port ranges  
- ✅ Validates IP and port inputs  
- ✅ Fast timeout for quick scanning  
- ✅ Clean and readable output  

---

## 🛠️ Requirements

- Python 3.x

No additional libraries required — uses Python's built-in `socket` module.
